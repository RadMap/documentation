RadMap Documentation
====================

RadMap is a desktop application for radiation dose rate calculations.
It uses the Geant4 Monte Carlo toolkit as its calculation engine and
provides a graphical interface for building geometry models, defining
radiation sources, setting up dose maps, and viewing results.

.. only:: html

   The documents of RadMap |release|:

   - `Documentation <documentation PDF_>`_ (PDF) -- installation, user
     guide, methods, EULA and third-party notices, as on these pages; also
     installed with RadMap.
   - `V&V report`_ (PDF) -- the verification and validation of this
     version, generated from the tests run on its build.
   - `Software development plan <development plan_>`_ (PDF) -- how RadMap
     is developed, verified, released and corrected.
